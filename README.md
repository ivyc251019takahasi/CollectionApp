Laravelについて
Laravelは、分かりやすく、美しい構文を持つWebアプリケーションフレームワークです。
Laravelでは、開発を楽しく創造的なものにすることを大切にしています。
多くのWebアプリケーションで必要となる一般的な作業を簡単にすることで、開発者の負担を減らします。
Laravelには、次のような機能があります。
- シンプルで高速なルーティング機能
- 強力な依存性注入コンテナ
- セッションやキャッシュを保存するための複数の仕組み
- 分かりやすく直感的なデータベースORM
- データベースの構造を変更・管理するマイグレーション機能
- バックグラウンドで処理を行うためのジョブ機能
- リアルタイム通信を行うためのイベントブロードキャスト機能
Laravelは、初心者にも扱いやすく、高機能で、大規模で安定したアプリケーションを作るためのツールも提供しています。   README
Laravelを学ぶ
Laravelには、非常に詳しい公式ドキュメントや動画チュートリアルがあります。
Laravelの公式ドキュメントを利用することで、Laravelの使い方を学ぶことができます。
また、Laravel Learnでは、現代的なWebアプリケーションを作りながらLaravelを学ぶことができます。   README
文章を読むより動画で学びたい場合は、Laracastsというサービスも利用できます。
Laracastsには、Laravelだけでなく、
- PHP
- ユニットテスト
- JavaScript
などについての動画教材が多数用意されています。   README

Laravelのコミュニティを誰にとっても歓迎される場所にするため、**Code of Conduct（行動規範）**を確認し、それを守るよう案内されています。   README
